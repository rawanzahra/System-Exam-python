# Exam System (Python)

## Description

A console-based Exam System developed in Python that allows an administrator to manage students and enables students to take exams and 
receive their scores automatically.

## Features

* Choose between **Manager** and **Student** mode.
* Manager authentication using a password (`1234`).
* Add new students to the system.
* assign a unique Student ID.
* Student login using the assigned Student ID.
* Take the exam.
* Automatic score calculation.
* Display the final score after completing the exam.

## Technologies Used

* Python
* Object-Oriented Programming (OOP)
* File Handling 

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the systemExam.py:

   ```bash
   systemExam.py
   ```

## System Workflow

1. The user selects either **Manager** or **Student**.
2. The **Manager** enters the password (`1234`).
3. The manager adds a new student.
4. The manager add a unique Student ID.
5. The student logs in using the assigned Student ID.
6. The student starts the exam.
7. The system calculates and displays the final score.
